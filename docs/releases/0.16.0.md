# 0.16.0 — Local image editing

- Windows: open **Settings and details → Edit picture** to crop, cover rectangular areas with opaque colors, blur areas, or add a local overlay image.
- Drag rectangles or enter percentages. Remove masks individually; reset crop or all edits. Up to 12 masks and one PNG/JPEG/WebP overlay (15 MB / 16 MP).
- Adjust overlay position, size and opacity. Editing happens locally, using the same processed output for the Windows camera and future recorded frames. No image upload.
- Opaque masks take precedence over overlapping blur. Processing errors clear the output, including the recording canvas, rather than showing unprocessed video.
- The four-language FAQ describes limitations: blur may leave recognizable details; check areas after camera/orientation changes; edits are cleared on app exit; extra processing can reduce frame rate.
- Retains 0.15.1 invitation timeout and signaling recovery corrections. Install the Windows update: refreshing the hosted phone page does not update the desktop receiver.

Validation: 81 automated tests passed; synthetic browser pixel checks covered crop, opaque masking, exterior pixels, blur, overlay, invalid values and editor controls. No physical camera or microphone was accessed. Physical phone/meeting-app validation remains manual.
