# 0.18.0 — Windows receiver redesign and fullscreen

- Steps across the top: Scan the QR code → Approve the code → Camera running → Choose in meeting app. The current step follows the pairing state.
- Video stage with a live chip, a recording chip and a resolution chip that opens the resolution selector directly.
- A last-step hint names the exact camera (extruda - mobile as webcam (W×H)) to choose in Teams, Zoom or Meet. "I've done that" hides it for later sessions.
- Toolbar grouped into Picture (resolution, Edit picture), Sound (microphone, level, noise reduction) and Record, with Settings and Disconnect at the end.
- Settings and details became a side panel with Picture, Sound, Recording and Connection sections. Esc closes it.
- Fullscreen: stage button, F11 or double-click. The window covers the whole monitor without frame or taskbar; Esc, F11 or double-click restores the previous window placement. Controls fade after 2.5 seconds without mouse movement; the recording indicator stays visible.
- The pairing view uses a larger QR code, and a maximized window uses the full width.
- New 26A icons: fullscreen and exit fullscreen.
- The old "video only" button is replaced by fullscreen.

Validation: all 88 automated tests pass, including new packaging checks that every UI script is copied, embedded and installed. The layout, settings panel and all fullscreen entry/exit paths were checked in the built Windows app with a test pattern. A physical phone pairing, recording in fullscreen and installation via the setup remain manual checks.
